# SigLIP 2 실험 실행 방법 (VS Code)

처음 한 번만 1~3단계를 하고, 그다음부터는 4단계만 하면 됩니다.

## 1. VS Code에서 프로젝트 폴더 열기

VS Code → 파일 → 폴더 열기 → 아래 폴더 선택

```
D:\개발\모두의연구소\내가만든거\3-8.AI이해하고 사용하기_내 업무 어디에 AI를 넣을까\MainQuest2
```

메뉴 **터미널 → 새 터미널**을 엽니다. 아래 명령은 모두 이 터미널에 한 줄씩 붙여 넣고 Enter를 누릅니다.

## 2. 실행 환경 만들기 (처음 한 번, 5~10분)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

- 줄 맨 앞에 `(.venv)`가 보이면 성공입니다.
- "스크립트를 실행할 수 없습니다" 오류가 나면 아래를 한 번 실행한 뒤 다시 해 보세요.
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
- "No suitable Python runtime found"가 나오면 3.11이 없는 것입니다. `py -0`으로 설치된 버전을 보고, 예를 들어 3.12가 있으면 `py -3.12 -m venv .venv`로 만드세요. (2026-11-17 실제로 3.12로 실행함)
- `pip install --upgrade pip`는 하지 마세요. VS Code가 파일을 잡고 있으면 pip가 반쯤 지워질 수 있습니다.

## 3. 필요한 프로그램 설치 (처음 한 번)

```powershell
$env:PYTHONUTF8 = '1'
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r code\siglip\requirements.txt
```

- 첫 줄(`PYTHONUTF8`)은 requirements.txt 안의 한글 주석을 제대로 읽게 해 줍니다. 빼면 `UnicodeDecodeError: 'cp949'` 오류가 납니다.

## 4. 실험 실행

```powershell
.\.venv\Scripts\Activate.ps1
$env:PYTHONUTF8 = '1'
python code\siglip\run_siglip.py
```

- `bos_token_id must be None ...` 경고는 설정 파일의 사소한 표기 문제라 무시해도 됩니다 (간단한 색깔 사진으로 모델이 정상 동작함을 확인함).

- 처음 실행할 때 SigLIP 2 모델(약 1.5GB)을 내려받느라 몇 분 걸립니다.
- 끝나면 화면에 이렇게 나옵니다.
  ```
  SigLIP2_제로샷: 패턴 ??%, 방향 ??%
  SigLIP2_분류기: 패턴 ??%, 방향 ??%
  ```
- 자세한 결과는 `진행기록\06_SigLIP2_실험_결과.json`에 저장됩니다.
