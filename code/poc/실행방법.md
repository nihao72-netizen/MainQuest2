# PoC 실행 방법 (VS Code 터미널)

> PoC의 자세한 실행 방법입니다. 전체 요약은 저장소 맨 위의 `README.md`에 있습니다.
> 모든 처리는 내 PC 안에서만 합니다. 캡처를 외부로 보내지 않습니다.

## 0. 준비 (처음 한 번)

```powershell
py -3.12 -m venv .venv                 # 이미 .venv가 있으면 건너뜀
.\.venv\Scripts\Activate.ps1
$env:PYTHONUTF8 = '1'
pip install torch==2.15.0 --index-url https://download.pytorch.org/whl/cpu
pip install -r code\poc\requirements.txt
```

## 1. 최종 모델 만들기 (학습용 사진이 바뀌었을 때만)

```powershell
python code\poc\train_final.py
```

- 학습용 68장 전체로 모델 2개를 만듭니다 (약 4분): `models\dir3.pt`(방향 3분류), `models\cls11.pt`(패턴 11분류)
- 옆의 `dir3.json`, `cls11.json`에 학습 날짜·사진 수·설정이 기록됩니다.

## 2. 차트 영역 좌표 정하기 (처음 한 번, HTS 창 위치나 크기를 바꿨을 때)

HTS 차트를 띄운 상태에서:

```powershell
python code\poc\setup_region.py --delay 5
```

- 5초 안에 HTS 창을 앞으로 가져옵니다.
- **HTS가 다른 모니터에 있으면 `--monitor 2`를 붙입니다** (세 번째 모니터면 `--monitor 3`).

  ```powershell
  python code\poc\setup_region.py --monitor 2 --delay 5
  ```

  모니터 번호를 모르겠으면: `python -c "import mss; print(mss.mss().monitors[1:])"` → 목록의 첫 번째가 1번입니다.
- 화면의 **위 차트 = "큰 봉"**, **아래 차트 = "작은 봉"**으로 부릅니다. 분봉(300분, 16분 등)은 수시로 바꾸므로 이름으로 쓰지 않습니다.
  찾은 후보 중 0번(가장 위)을 큰 봉, 1번을 작은 봉으로 저장합니다. 다른 후보를 쓰려면 `--top 0 --bottom 2`처럼, 작은 봉 차트를 안 쓰려면 `--bottom -1`.
- 끝나면 `logs\setup\<시각>_큰봉_영역.png`, `<시각>_작은봉_영역.png`가 생깁니다. **각각 그래프 영역만 잘렸는지 눈으로 확인**하세요.
- 좌표는 `code\poc\config.json`의 `charts`에 저장됩니다. 차트를 하나만 찾으면 작은 봉 차트의 이전 설정은 그대로 둡니다.

### 봉 간격 (`bar_px`) — 차트마다 따로

"봉 간격"은 **봉 하나가 화면에서 가로로 차지하는 폭(픽셀)** 입니다. 프로그램은 이 값으로 "최근 150봉"이 화면에서 몇 픽셀인지 계산합니다.

| 차트 | 지금 설정 | 어떻게 정했나 (2026-11-17, 모니터 2) |
| --- | --- | --- |
| 큰 봉 (화면 위) | 11px (화면에 약 330봉) | 처음엔 3.6px(봉이 서로 붙음)이었으나, 사용자가 HTS에서 확대해 봉 사이에 빈틈이 생기게 함 → 빈틈 세기 11px, 확대 사진에서도 11px |
| 작은 봉 (화면 아래) | 11px (화면에 약 330봉) | 봉 사이 빈틈을 세는 방법과 반복 무늬 방법이 모두 11px |

- **HTS에서 차트를 확대·축소하면** 봉 간격이 바뀝니다. 프로그램이 판정할 때마다 봉 간격을 다시 재서, 설정과 2px 이상 다르면 "차트 확대 비율이 바뀐 것 같다" 경고를 남깁니다.
- 큰 봉처럼 봉이 서로 붙어 있는 차트는 간격을 잴 수 없어서 "측정 안 함(봉이 붙음)"으로 남깁니다. 그래도 확대해서 빈틈이 생기면 경고합니다. 빈틈이 있어야 할 작은 봉 차트가 축소되어 붙어 보여도 경고합니다.
- **분봉만 바꾸는 것**(예: 300분 → 60분)은 확대 비율과 상관이 없어 다시 정할 필요가 없습니다.
- 확대 비율을 일부러 바꿨다면 봉 간격을 다시 정해야 합니다(Claude에게 "봉 간격 다시 재 줘"라고 요청).
- 화면 전체 사진은 기본으로 **저장하지 않습니다** (계좌·주문 정보 보호). 꼭 필요할 때만 `config.json`에서 `"save_full_screenshot": true`로 바꿉니다.

## 4. PoC 실행 (알림·기록)

```powershell
python code\poc\run_poc.py --once        # 한 번만
python code\poc\run_poc.py               # 5분마다 반복 (멈추려면 Ctrl+C)
python code\poc\run_poc.py --interval 3  # 3분마다
python code\poc\run_poc.py --charts 큰봉  # 큰 봉 차트만 (기본은 큰 봉·작은 봉 둘 다)
```

- 화면 위 **큰 봉** 차트와 아래 **작은 봉** 차트를 차례로 판정합니다. 콘솔에 `[큰 봉] …`, `[작은 봉] …`, `[진입 확인] …` 세 줄이 나옵니다.
- 분봉 이름(300분 등)은 기록하지 않습니다. 기록에는 "큰 봉 / 작은 봉"만 남습니다.

### 진입 확인

- **큰 봉의 알림 방향 = 작은 봉의 알림 방향**일 때만 "진입 확인"입니다. 예: 큰 봉 알림(하락) + 작은 봉 알림(하락) → 진입 확인(하락).
- 한쪽이라도 "애매", "없음", "확인 불가"이거나 방향이 다르면 "아님"입니다. 콘솔에 이유가 나옵니다. 예: `[진입 확인] 아님 — 큰 봉 알림(하락), 작은 봉 알림(상승)`
- 알림 창은 **하나만** 뜹니다. 우선순위: "진입 확인 (주문은 직접)" 창 > "큰 봉 방향 알림 (주문은 직접)" 창. 같은 상태가 이어지면 다시 띄우지 않습니다.
- 큰 봉 알림 창은 끄고 **진입 확인 창만** 받으려면 `config.json`에서 `"popup_big_alert": false`.
- 판정마다 `logs\진입확인기록.csv`에 한 줄: 진입 확인 예/아니오, 방향, 두 차트의 판정, 설정값, 모델.
- **주문은 사람이 합니다.** 진입 확인은 "두 차트의 방향이 같다"는 뜻일 뿐, 매수·매도 신호나 투자 조언이 아닙니다.

- **실행하는 동안 HTS 차트가 다른 창에 가려지지 않게** 두세요. 가려지면 판정하지 않고 "확인 불가"만 남깁니다(사진도 저장 안 함).
- 콘솔 한 줄 예: `2026-11-17 22:03:13 | 알림(하락) [150봉 창 기준] | 150봉 창: 3분류 하락 점수 0.99… | 11분류 참고: 역N자형 모양과 비슷 (하락) 점수 0.66… | 다른 창: 100봉 애매, 200봉 알림`
- "알림"일 때만 윈도우 알림 창이 뜹니다. 같은 알림이 계속되면 다시 띄우지 않습니다(`popup_only_on_change`). 끄려면 `--no-popup`.
  - `--once`: 알림 창을 **닫을 때까지 프로그램이 기다립니다** (예전에는 프로그램이 끝나면서 창이 바로 꺼졌음).
  - 반복 실행: 판정은 멈추지 않고, 새 알림이 오면 이전 알림 창을 닫고 새 창 하나만 띄웁니다 (창이 쌓이지 않음).
- **주문은 사람이 합니다.** 이 프로그램은 매매와 연결되어 있지 않습니다.

### 남는 기록 (`logs\`, GitHub에 올라가지 않음)

| 파일 | 내용 |
| --- | --- |
| `판정기록*.csv` | 차트 하나의 창 하나 = 한 줄. 시각, **차트(큰 봉/작은 봉)**, 최종 판정, 창별 판정, **두 모델의 모든 점수(반올림 없음)**, 모델 파일(학습 날짜·지문), 설정값(창 폭·규칙·묶는 방식·기준 창·봉 간격), 경고. 엑셀로 열 수 있음 |
| `captures\<시각>_<큰봉\|작은봉>.png` | 캡처한 **차트 영역만** (화면 전체는 저장 안 함) |
| `windows\<시각>_<차트>_창<N>.png` | 모델에 실제로 넣은 사진 (창마다) |
| `images\<시각>_<차트>_확인.png` | 결과 글자를 얹은 확인용 이미지 |
| `오류기록.txt` | 실행 중 오류 |

| `실전시험\사진\<실행ID>_<차트>.png` | 정답 적기용 깨끗한 차트 (결과 글자·색 없음, 회색 점선 = 기준 창 시작). **자동으로 지우지 않음** |
| `실전시험\정답표.csv` | 실행ID, 차트, 시각, 사진, 정답(빈칸), 라벨의심, 메모 — **판정 결과는 들어 있지 않음** |

사진은 폴더마다 `keep_captures`장(기본 2000)을 넘으면 오래된 것부터 지웁니다(실전시험 사진은 제외). `--keep 500`처럼 바꿀 수 있습니다.
코드가 바뀌어 CSV 열 구성이 달라지면 `판정기록_v2.csv`처럼 새 파일에 이어서 씁니다. 채점 스크립트는 모든 판정기록 파일을 읽습니다.

## 5. 시험

### 5-1. 전처리 일치 테스트 (코드를 고친 뒤마다)

```powershell
python code\poc\test_preprocess.py
```

같은 원본캡처를 학습 경로·판정 경로로 처리해 결과(사진·점수)가 같은지 등 14개를 확인합니다. "전부 통과"가 나와야 합니다.

### 5-2. 모델 시험 (`data\시험용` 사진으로)

1. 매매하며 찍은 새 캡처를 **먼저** `data\시험용\<패턴>\`에 넣습니다 (정답 = 폴더, 모델을 돌리기 전에 정함).
2. 실행: `python code\poc\evaluate_model.py`
3. 결과: `진행기록\시험결과\모델시험_<시각>.md` — 방향·패턴 정답률(3분류, 11분류, 규칙 코드, 늘 상승 찍기), 알림 규칙별 **3분류 점수 최소값 0.0–0.9 표**, 사진별 결과
4. 결과를 본 뒤 라벨이 의심되면 **폴더를 옮기지 말고** `data\시험용\라벨의심.csv`에 `파일,메모`(예: `횡보/3.png,하락 시작으로도 보임`)로 적습니다. 점수는 원래 정답으로 매기고 목록만 따로 보여 줍니다.
5. 시험이 끝난 사진만 학습용으로 옮기고 재학습합니다 (진행기록/04).

### 5-3. PoC 실전 시험 (실제 화면 판정을 나중에 채점)

1. `run_poc.py`를 평소처럼 돌립니다. 판정마다 차트별로 `logs\실전시험\사진\<실행ID>_<큰봉|작은봉>.png`과 `정답표.csv`(전체 목록) 한 줄이 자동으로 생깁니다.
2. 사진이 충분히 쌓이면 **표본 정답표**를 만듭니다 (권장):

   ```powershell
   python code\poc\evaluate_practice.py --make-sample                                 # 차트마다 서로 3시간 이상 떨어진 사진 40장, 순서 섞음
   python code\poc\evaluate_practice.py --make-sample --min-gap-hours 24 --count 30   # 간격·장수 바꾸기
   python code\poc\evaluate_practice.py --make-sample --chart 큰봉                      # 큰 봉 차트만
   ```

   - 결과: `logs\실전시험\표본_<시각>\` 폴더 — `01.png`, `02.png`…(섞인 순서, 이름에 시각 없음, 큰 봉·작은 봉도 섞임), `정답표.csv`(번호·차트·정답 칸), `_매핑.csv`(번호→실행ID, 채점용)
   - **왜 표본인가:** 봉 하나가 몇 시간짜리일 수도 있어서, 5분마다 찍은 판정 사진은 거의 같은 그림입니다. 그대로 채점하면 같은 문제를 수십 번 센 것이 되어, 점수가 실제보다 확실해 보입니다. 그래서 서로 떨어진 사진만 골라 순서를 섞어 정답을 적습니다.
   - **간격을 정할 때 참고:** 만들 때 차트마다 "고른 사진끼리 가장 가까운 간격(시간)"이 나옵니다. 분봉을 기록하지 않으므로 봉 몇 개가 바뀌었는지는 계산하지 않습니다. 예를 들어 봉 하나가 5시간이면 3시간 간격으로는 새 봉이 1개도 생기지 않아, 150봉 창이 거의 그대로입니다. 큰 봉 차트를 긴 분봉으로 볼 때는 간격을 늘리세요.
   - 서로 떨어진 사진이 목표 장수보다 적으면 있는 만큼만 고르고 경고를 보여 줍니다. 이전 표본에 쓴 사진은 기본으로 빼서 다시 고르지 않습니다(`--include-used`로 바꿈).
3. **나중에** 표본 폴더의 사진만 보고 `정답표.csv`의 `정답` 칸에 `상승` / `하락` / `없음`을 적습니다. 기준: 회색 점선(150봉 시작)부터 오른쪽 끝까지의 방향.
   - **정답을 다 적기 전에는 `logs\판정기록*.csv`와 `logs\images\`를 열지 마세요.** 판정을 보면 정답이 흔들립니다.
   - 애매하면 정답은 적고 `라벨의심`에 `O`, 이유는 `메모`에 씁니다.
4. 다 적은 뒤: `python code\poc\evaluate_practice.py` → **가장 최근 표본**으로 채점합니다. 다른 표본이나 전체 목록을 채점하려면 `--sheet 표본_<시각>` 또는 `--sheet 정답표.csv`를 붙입니다(전체 목록은 연속 사진이 섞여 있어 권장하지 않음).
   - 전체 정답표를 엑셀로 열어 둔 사이에 판정이 돌면 줄이 추가되지 않을 수 있습니다 → `--sync`로 빠진 줄을 채웁니다(판정 결과는 보여 주지 않음).
5. 결과: `진행기록\시험결과\실전시험_<시각>.md` — 어떤 정답표로 채점했는지, 그때 쓴 설정의 결과, 창 폭별 정확도, **창 묶기 3방식(main·all_agree·majority) × 3분류 점수 최소값 0.0–0.9 표**, 라벨 의심 목록
6. 한계: 판정 중에 콘솔·알림 창으로 결과를 이미 봤을 수 있습니다. 가능하면 며칠 지난 뒤 정답을 적으세요.

## 6. 분봉별 시험 (300분봉으로 학습한 AI가 다른 분봉에서도 통하는지)

> 패턴은 300분·10분·1분 등 분봉과 상관없이 비슷하게 나타난다(사용자의 다년간 매매 경험). 이 PoC는 300분봉으로 학습한 AI가 다른 분봉에서도 같은 패턴을 알아보는지를 시험으로 확인한다.

### 사진을 넣을 폴더

`data\시험용_분봉\<분봉>\` — 찍기 도우미가 알아서 만들고 저장합니다. **분봉 이름은 이 폴더 이름에만** 씁니다(실시간 기록에는 쓰지 않음).

```text
data\시험용_분봉\
  10분\    10분_01.png … 10분_30.png
  60분\    60분_01.png … 60분_30.png
  300분\   300분_01.png …            ← 기준 (학습한 분봉)
```

### 몇 장, 얼마나 옮겨서

| 분봉 | 장수 | 한 장마다 과거로 옮기는 양 |
| --- | --- | --- |
| 10분 | 30장 | 한 화면 폭 (약 2.5거래일) |
| 60분 | 30장 | 한 화면 폭 (약 15거래일). 과거 자료가 모자라면 화면의 2/3 |
| 300분 (기준) | HTS에 남은 만큼, 10장 이상 | 화면의 2/3 이상. **학습 사진(원본캡처)을 찍을 때 화면에 보이던 기간보다 더 과거**에서 |

- **왜 "한 화면 폭"인가:** 판정은 오른쪽 끝에서 최대 200봉까지만 봅니다. 지금 큰 봉 차트는 한 화면에 약 330봉이 보입니다. 한 화면만큼 옮기면 사진끼리 판정 범위가 전혀 겹치지 않아, 같은 문제를 두 번 세지 않습니다. 화면의 2/3(약 220봉)만 옮겨도 200봉 창은 겹치지 않습니다.
- **옮기는 법:** HTS 큰 봉 차트를 마우스로 오른쪽으로 끌어 과거로 옮깁니다. **화면 오른쪽 끝에 있던 봉이 왼쪽 끝 밖으로 나갈 때까지** 옮기면 한 화면 폭입니다(2/3면 그 봉이 왼쪽에서 1/3쯤에 올 때까지).
- **고르지 말고 차례로:** 모양이 좋아 보이는 곳만 고르면 시험이 쉬워집니다. 한 화면씩 옮기며 나오는 대로 찍습니다.
- **확대 비율은 그대로:** 분봉만 바꾸고 확대·축소는 하지 않습니다(봉 간격 11px). 확대 비율이 다르면 도우미가 저장하지 않고 알려 줍니다.
- **HTS 봉은 속이 찬 봉**으로 둡니다.

### 순서

1. HTS **큰 봉 차트(화면 위)** 를 시험할 분봉(예: 10분)으로 바꾸고, 차트를 과거로 옮깁니다.
2. 터미널에서 찍기 도우미를 켭니다:

   ```powershell
   python code\poc\capture_test.py 10분            # 목표 30장
   python code\poc\capture_test.py 300분 --count 10
   ```

3. **Enter** → 큰 봉 차트 영역만 저장. HTS로 가서 한 화면 폭만큼 과거로 옮기고 → 터미널로 와서 다시 **Enter**. 목표 장수까지 반복합니다(`q` + Enter = 중간에 끝, 다음에 다시 켜면 이어서 번호를 붙임).
   - 저장 안 하는 경우: 차트가 다른 창에 가려짐 / 확대 비율이 다름 / 바로 전 사진과 거의 같음(차트를 안 옮김). 이유가 나오면 고치고 다시 Enter.
   - **판정 결과는 보여 주지 않습니다.**
4. 다른 분봉도 1–3을 반복합니다 (60분, 300분).
5. 다 찍었으면 정답 적기 폴더를 만듭니다:

   ```powershell
   python code\poc\evaluate_timeframe.py --make-sheet
   ```

   → `data\시험용_분봉\정답적기_<시각>\` : `01.png` … (**모든 분봉을 섞은 순서**, 이름에 분봉 없음, 회색 점선 = 150봉 창 시작), `정답표.csv`(번호·정답 칸), `_매핑.csv`(채점용)
6. 그 폴더의 사진만 보고 `정답표.csv`의 `정답` 칸에 `상승` / `하락` / `없음`을 적습니다. 기준: 회색 점선부터 오른쪽 끝까지의 방향. 애매하면 `라벨의심`에 `O`, 이유는 `메모`에.
   - **이때까지 모델은 한 번도 돌지 않았습니다.** 판정은 어디에도 없으니, 분봉도 판정도 모르는 채로 적게 됩니다.
7. 채점: `python code\poc\evaluate_timeframe.py` → `진행기록\시험결과\분봉시험_<시각>.md`
   - 이때 처음으로 PoC 판정(run_poc와 같은 함수, 큰 봉 차트 설정)을 돌려 **분봉별로 따로** 채점합니다: 3분류·11분류 방향 정답률, 알림 정확도, 위험한·반대 알림, 창 폭별, 창 묶기 3방식 × 최소값 0.0–0.9.
   - 300분봉 줄이 기준입니다. 다른 분봉이 300분봉과 비슷하면 "분봉과 상관없이 통한다"는 쪽, 많이 낮으면 아니라는 쪽 근거입니다.

## 7. 실전 기록 (만드는 중)

아무 때나 단축키(Ctrl+Alt+J)로 큰 봉 차트를 찍고 내 판단(오른다 / 내린다 / 모르겠다)을 고르면, 30분·2시간·1일 뒤 현재가를 OCR로 읽어 실제로 올랐는지 내렸는지 자동으로 적습니다. AI 판정은 그때 보여 주지 않고 따로 기록만 합니다.

### 7-1. 현재가 읽기 확인 (처음 한 번, HTS 창 배치를 바꿨을 때)

현재가는 **두 곳을 한 장으로 같이 찍어** 읽습니다. 따로 지정할 필요가 없습니다.

| 읽는 곳 | 위치 | 특징 |
| --- | --- | --- |
| ① 차트 위 현재가 칸 | 큰 봉 차트 창의 도구 모음 바로 아래 줄 왼쪽 끝 (예: `27164.25▼`) | 위치가 고정됨. 큰 봉 그래프 영역 왼쪽 위에서 오른쪽 14px, 위쪽 37px (`config.json`의 `price_field`) |
| ② 가격 축 현재가 상자 | 큰 봉 차트 오른쪽 가격 축의 빨강·파랑 상자 (예: `27161,00`) | 가격에 따라 위아래로 움직임 → 찍을 때마다 자동으로 찾음 |

- 같은 순간의 두 값이 **5포인트 이내로 같으면** 그 값을 씁니다(①의 값). HTS가 두 칸을 아주 조금 다른 순간에 그려서 1–2포인트 다를 수 있습니다.
- **한 곳만 읽히면** 그 값을 쓰고 "현재가 칸만 / 가격 축만"으로 표시합니다.
- **5포인트보다 많이 다르거나 둘 다 못 읽으면** 1초 간격으로 3번까지 다시 읽고, 그래도 안 되면 "읽기 실패"로 남깁니다.
- 검산용으로 ①과 ②를 잘라 붙인 작은 사진을 남깁니다.

**확인하는 법 (클릭 순서):**

1. VS Code 메뉴 **터미널 → 새 터미널**을 클릭합니다.
2. 아래 세 줄을 한 줄씩 붙여 넣고 Enter를 누릅니다.

   ```powershell
   .\.venv\Scripts\Activate.ps1
   $env:PYTHONUTF8 = '1'
   python code\poc\setup_price.py
   ```

3. 2초 간격으로 5번 읽은 결과가 나옵니다. 예: `1: 가격 27182.75 [두 곳 일치] (현재가 칸 27182.75, 가격 축 27181.75, 시도 1번)`
4. HTS 현재가와 같은지 봅니다. 검산용 사진은 `logs\setup\<시각>_현재가_N.png`에 있습니다.

**주의:**

- **마우스를 큰 봉 차트 위에 두지 마세요.** 십자선 가격 상자(파랑, 0.25 단위가 아닌 값)가 생겨 ②가 가려지거나 헷갈릴 수 있습니다. 프로그램은 마지막 봉 높이에 있는 상자만 현재가로 보므로 잘못 기록하지는 않지만, ②를 못 읽게 됩니다.
- **차트 안에 띄운 호가표는 필요 없습니다.** 현재가는 ①·②로 읽습니다. 호가표의 파랑·분홍 가격 글자가 봉처럼 잡히고, 회색 칸 때문에 "가려짐" 판단에 가까워집니다(회색 비율이 평소의 약 5배). 지금은 판정 창(오른쪽 끝에서 200봉)과 겹치지 않아 판정에는 영향이 없었습니다. 하지만 **차트에서 호가표를 닫는 것을 권장**합니다.
- HTS 창 배치(도구 모음 줄 높이 등)를 바꿔 ①이 계속 실패하면, 예전 방식으로 직접 지정할 수 있습니다: `python code\poc\setup_price.py --drag` (두 번 드래그해 ①의 숫자만 감싸기).

### 7-2. 내 판단 기록하기 (단축키 Ctrl+Alt+J)

**켜기 (클릭 순서):**

1. **run_poc.py가 켜져 있으면 먼저 끕니다.** 그 터미널을 클릭하고 Ctrl+C를 누릅니다. run_poc는 AI 판정을 콘솔과 알림 창에 보여 주기 때문입니다.

6. **[오른다] / [내린다] / [모르겠다]** 중 하나를 클릭합니다. 창이 닫히고 터미널에 `기록 #… 저장: 오른다 [큰 봉 300분], 현재가 …`가 나옵니다.

### 7-3. 정해 둔 시간 뒤 가격 (자동)

기록할 때마다 **30분 뒤, 2시간 뒤, 1일 뒤** 현재가를 자동으로 읽어 `logs\실전기록\가격결과.csv`에 남깁니다. 따로 할 일은 없습니다.

- **record_live.py가 켜져 있어야 읽습니다.** 터미널에 `[30분 뒤] 기록 #…: 현재가 27100.25 (변화 +38.00, 3초 늦게)`처럼 나옵니다.
- **조금 늦어도 인정하는 범위:** 30분 뒤는 3분, 2시간 뒤는 12분, 1일 뒤는 30분까지입니다. 그보다 늦으면(그 시각에 프로그램이 꺼져 있었으면) **"놓침"** 으로 남습니다. 1일 뒤까지 받으려면 다음 날 같은 시각에도 켜 두어야 합니다.
- **껐다 켜도 됩니다.** 켤 때 아직 안 지난 예정 시각을 다시 잡습니다(`이전 기록에서 다시 잡은 것 N개`).
- 현재가를 못 읽으면 30초마다 다시 시도하고, 허용 범위를 넘기면 **"읽기실패"** 로 남깁니다. 그 시각에 HTS 큰 봉 차트가 화면에 보여야 합니다.
- **기준 폭:** 30분 20포인트, 2시간 40포인트, 1일 100포인트. 이만큼 이상 오르면 "올랐음", 내리면 "내렸음", 그 사이는 "변동 작음"입니다. `가격결과.csv`에는 **가격과 변화량**이 남아서, 나중에 기준 폭을 바꿔 결과를 다시 계산할 수 있습니다. 기준은 `config.json`의 `horizons`에 있습니다.

  ```json
  "horizons": [
    {"이름": "30분", "분": 30, "기준폭": 20},
    {"이름": "2시간", "분": 120, "기준폭": 40},
    {"이름": "1일", "분": 1440, "기준폭": 100}
  ]
  ```

- 주말·휴장 시간에 예정 시각이 걸리면 마지막 가격을 읽게 됩니다(변동 작음이 많아질 수 있음).

| `가격결과.csv` 열 | 뜻 |
| --- | --- |
| 기록ID, 시간 | 어느 기록의 몇 분 뒤인지 |
| 예정시각, 읽은시각, 늦음_초 | 언제 읽어야 했고 실제로 언제 읽었는지 |
| 상태 | 읽음 / 놓침 / 읽기실패 |
| p0, p1, 변화 | 기록 때 가격, 그 시간 뒤 가격, p1 − p0 |
| 기준폭, 결과_기록당시 | 그때 기준 폭과 그 기준의 결과 (결과 표에서는 지금 기준으로 다시 계산) |
| 출처, 가격사진 | 현재가를 어디서 읽었는지(두 곳 일치 / 현재가 칸만 / 가격 축만), 검산용 사진 |

| 목표 판정 | problem_definition.md 5장의 ⑪⑫⑬ 통과 / 미달 / 판단 보류 (⑪은 큰 봉 알림 10건 이상, ⑫는 같을 때 10건 이상, ⑬은 그 분봉과 300분봉 모두 AI 큰 봉 알림 10건 이상일 때만 판단) |
| 적중률 | **내 판단**, **AI** 5가지(큰 봉 3분류, 큰 봉 알림, 작은 봉 3분류, 작은 봉 알림, 진입 확인), **늘 오른다 / 늘 내린다**(비교 기준). 각각 맞음/방향을 말한 수, 반대, 변동 작음, 변동 작음 뺀 적중률 |
| 나와 AI가 같을 때 | AI 5가지 각각에 대해, 내 판단과 같은 방향이었던 기록만의 적중률. 옆에 "다를 때 내 판단의 적중률"도 |
| 모르겠다일 때 | 내가 "모르겠다"였던 기록이 실제로 올랐는지·내렸는지·변동 작았는지 |
| 큰 봉 분봉별 | 선택 창에서 고른 분봉별로 내 판단, AI 큰 봉 알림·3분류, 진입 확인, 늘 오른다. 분봉을 안 고른 예전 기록은 "미입력" |
| 기준 폭 바꿔 보기 | 기준 폭 0, ½, 1, 2배에서 내 판단과 AI 큰 봉 알림 적중률 |
| 집계 | 채점한 기록 수, 놓침, 읽기실패, p0 없음, 현재가 출처 |

- **"변동 작음"은 틀린 것으로** 셉니다(오른다고 했는데 기준 폭만큼 오르지 않음). 변동 작음을 뺀 적중률도 함께 보여 줍니다.
- **비교 기준보다 높아야 의미가 있습니다.** 예를 들어 그 기간에 대부분 올랐다면 "늘 오른다"도 적중률이 높게 나옵니다.
- 같은 날 가까운 시각의 기록은 같은 가격 흐름을 공유해 서로 독립이 아닙니다. 기록한 날 수도 함께 보세요.

## 설정 (`code\poc\config.json`)

| 값 | 기본 | 뜻 |
| --- | --- | --- |
| `monitor`, `region` | 좌표 도우미가 채움 | HTS가 있는 모니터와 차트 영역 |
| `save_full_screenshot` | false | 좌표 도우미에서 화면 전체 사진을 남길지 |
| `keep_captures` | 2000 | 사진 보관 개수 |
| `interval_min` | 5 | 반복 간격(분) |
| `window_bars` | [100, 150, 200] | 판정 창 폭(봉 수). 마지막 봉에서 끝나는 최근 N봉 |
| `bar_px` | 9 | 봉 하나의 간격(픽셀). HTS 확대 비율을 바꾸면 다시 재야 함 |
| `bar_px_warn_diff` | 2 | 잰 봉 간격이 `bar_px`와 이만큼 다르면 "차트 확대 비율이 바뀐 것 같다" 경고 |
| `rule` | agree | 창 하나의 규칙. agree = 두 모델이 같은 방향일 때만 알림 / dir3_only = 3분류만 |
| `min_dir3_score` | 0.0 | 3분류 점수(1위)가 이보다 낮으면 알림 대신 "애매". 0 = 점수를 보지 않음. **시험 결과를 보고 정함** |
| `practice_test` | true | 판정마다 실전 시험용 사진·정답표 줄을 남길지 |
| `window_combine` | main | 창 묶기. main = `main_bars` 창 기준 / all_agree = 모든 창이 같을 때만 / majority = 과반 |
| `main_bars` | 150 | main 방식의 기준 창 |
| `chart_gray_max_total`, `chart_gray_max_tile` | 0.01, 0.04 | 회색·검정 픽셀이 이보다 많으면 "다른 창에 가려짐"으로 보고 판정하지 않음 |
| `popup`, `popup_only_on_change` | true, true | 알림 창 띄우기, 같은 알림 반복 안 함 |
| `popup_big_alert` | true | 진입 확인이 아닐 때 큰 봉 알림만으로도 창을 띄울지 (false면 진입 확인 창만) |
| `charts` | 큰 봉·작은 봉 | 차트별 화면 영역(`region`)과 봉 간격(`bar_px`, 큰 봉 3.6 / 작은 봉 11) |

### 자주 나는 문제

| 증상 | 해결 |
| --- | --- |
| "초록 날짜 축을 찾지 못했습니다" | HTS가 다른 모니터에 있는지 확인 → `--monitor 2`. 차트가 다른 창에 가려졌으면 `--delay 5`로 다시 |
| 확인용 사진에 다른 차트가 잘림 | `--pick 1`(위에서 두 번째)로 다시 |
| "확인 불가 … 차트가 다른 창에 가려진 것 같다" | HTS 차트 위에 다른 창이 있음. 창을 치우거나 HTS를 다른 모니터 맨 앞에 둠 |
| "차트 확대 비율이 바뀐 것 같다" | HTS 차트를 확대·축소했거나 창 크기를 바꿈 → 원래대로 돌리거나, `setup_region.py`를 다시 하고 `judge.py --live` 출력의 "측정 …px" 값으로 `bar_px`를 바꿈 |
| 확인용 이미지 아래쪽(모델 입력) 사진이 아주 흐림 | **HTS 봉은 속이 찬 봉으로 둘 것.** 속이 빈 봉(테두리만)은 줄이면 선이 옅어져 학습 사진과 다른 그림이 됩니다. HTS 차트 설정에서 봉을 속이 찬 봉으로 바꿉니다 (진행기록 12의 8장) |
| `UnicodeDecodeError: 'cp949'` | `$env:PYTHONUTF8 = '1'`을 먼저 실행 |
