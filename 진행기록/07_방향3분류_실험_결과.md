# 6단계. YOLO 방향 3분류 vs 패턴 11분류 (2026-11-17)

## 한 줄 결과

**같은 조건에서 비교하니 방향만 고르는 3분류 모델이 방향 89%로, 11분류 모델(83%)보다 높았다. 직접 캡처 16장에서는 13/16 대 10/16이었다. 다만 사진이 64장뿐이라 차이가 통계적으로 확실하지는 않다(p = 0.29).**

## 왜 이 실험을 했나

알림 도우미에 가장 먼저 필요한 것은 "지금 큰 봉이 **오르는 쪽인지, 내리는 쪽인지**"다. 11개 패턴 이름을 모두 맞히지 않아도 방향만 맞으면 쓸 수 있다. 그래서 처음부터 방향(상승/하락/없음)만 배우게 하면 더 잘 맞히는지 확인했다.

## 실험 조건

| 항목 | 내용 |
| --- | --- |
| 모델 | YOLO11n-cls (사전학습 가중치에서 파인튜닝), 40 epoch, 224px, CPU, seed 0 |
| 데이터 | 학습용 64장. 방향별: 상승 31, 하락 29, 없음(횡보) 4 |
| 3분류 라벨 | 쌍바닥·삼중바닥·역헤드앤숄더·N자형·상승추세 → 상승 / 쌍봉·삼중천장·헤드앤숄더·역N자형·하락추세 → 하락 / 횡보 → 없음 |
| 늘리기 | 학습 때만 위아래 뒤집기 + 빨강·파랑 맞바꾸기 (방향도 반대로: 상승↔하락, 없음은 그대로) |

| 11분류의 방향 점수 | 예측한 패턴을 방향으로 바꿔서 채점 (예: "쌍봉" → 하락) |
| 코드 | `code/yolo_direction/run_yolo_direction.py`, 상세 예측: `07_방향3분류_실험_결과.json` |
| 걸린 시간 | 모델 10개(5겹 × 2종) 학습·예측에 약 15분 |

## 결과

| 후보 | 패턴 | 방향 | 직접 캡처 16장 방향 |
| --- | --- | --- | --- |
| 늘 "상승" 찍기 | — | 48% | 10/16 |
| SigLIP 2 + 분류기 (06) | 31% | 59% | 8/16 |
| YOLO 11분류 (05, 클라우드) | 50% | 75% | 10/16 |
| YOLO 11분류 (이번, 내 PC 재실행) | 56% | 83% | 10/16 |
| **YOLO 방향 3분류 (이번)** | — | **89%** | **13/16** |

> 11분류는 클라우드 첫 실험(50%·75%)과 이번 재실행(56%·83%)의 숫자가 다르다. 프로그램 버전·컴퓨터가 달라서 학습 결과가 조금씩 달라진 것으로 보인다. **사진 64장에서는 몇 장 차이로도 숫자가 크게 움직인다**는 뜻이므로, 3분류와의 비교는 같은 환경에서 함께 돌린 이번 숫자(83% vs 89%)로 한다.

### 차이가 우연일 가능성

- 두 모델이 모두 맞힘 51장, 모두 틀림 5장, **3분류만 맞힘 6장, 11분류만 맞힘 2장**.
- 6 대 2의 차이를 맥니마 검정(같은 사진에 두 모델을 비교하는 방법)으로 보면 p = 0.29. "차이가 우연히 생겼을 확률이 약 29%"라는 뜻이라 **확실하다고 말할 수 없다.** 시험용 사진을 모아 다시 재야 한다.

| ① 방향 판정 | 80% | 89% | 83% | 교차검증에서는 둘 다 넘음. 단 기준은 **새 시험 사진 30장**으로 재는 것이므로 아직 "통과 가능성 확인" 단계 |

## 틀린 경우에서 보인 것

1. **11분류의 실수는 대부분 같은 방향 안에서 일어난다.** 삼중바닥 → 쌍바닥(3건), 삼중천장 → 쌍봉(2건)처럼 패턴 이름은 틀려도 방향은 맞는 경우가 많다. 그래서 패턴은 56%인데 방향은 83%가 나온다. 3분류는 이런 헷갈림 자체를 묻지 않으니 유리하다.
2. **"없음"(횡보)은 둘 다 약하다.** 4장뿐이라 거의 배우지 못했다(3분류 2/4, 11분류 1/4). 횡보 3장을 "상승"이나 "삼중천장"으로 답했다. 실제 매매에서는 "없음"을 "상승/하락"으로 잘못 알리면 애매한 자리에 진입하게 되므로 **가장 위험한 실수**다.
3. **3분류만 틀린 2건**: `쌍봉_04_원본02`, `역N자형_08_원본10`을 "상승"으로 답함. 11분류는 둘 다 맞혔다. 같은 원본02 화면의 `쌍봉_03`은 11분류가 N자형(상승)으로 틀려, 이 화면이 원래 애매한 모양일 수 있다.
4. **직접 캡처 16장에서 11분류(10/16)는 "늘 상승 찍기"(10/16)와 같았다.** 사람이 자른 사진(크기·여백 제각각)에서는 11분류가 아직 쓸모를 보여 주지 못했다. 3분류는 13/16.

## 결론

- **알림의 첫 단계(방향 판정)는 3분류 모델로 하는 쪽이 유력하다.** 같은 조건에서 더 높고, 직접 캡처 사진에서도 더 잘 맞혔다.
- 패턴 이름(쌍바닥, N자형 등)은 알림의 **보조 정보**로 11분류 모델이 함께 알려 주는 구성을 생각할 수 있다. 예: "상승 쪽 (참고: 쌍바닥과 비슷)".
- 단, 64장·한 번의 학습으로 얻은 결과라 차이가 확실하지 않다. **시험용 사진으로 다시 재는 것이 먼저**다.
