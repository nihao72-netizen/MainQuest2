## 틀린 경우에서 보인 것 (실패 분석 첫 기록)

1. **N자형 → 쌍봉 (5건):** 오르다 눌린 뒤 다시 오르는 모양의 꼭대기 부분이 봉우리 두 개처럼 보임. 사진 오른쪽 끝(마지막 상승)이 짧게 잘린 경우가 많음.
2. **쌍봉 쪽으로 쏠림:** 쌍봉이 가장 많은 사진(15장 + 뒤집은 쌍바닥 10장)이라, 애매하면 쌍봉으로 답하는 경향.
3. **삼중바닥 ↔ 횡보:** 바닥이 얕은 삼중바닥은 횡보와 구분이 어려움. 사람에게도 애매한 사진.
4. **규칙 코드는 직접 캡처 사진에 약함 (6/16):** 사람이 자른 사진은 크기·여백이 제각각이라 규칙이 고점·저점을 다르게 잡음.

## 다음에 할 일

1. 매매하며 새 캡처를 `시험용`에 모으기 → 공정한 시험 (규칙 코드 점수 부풀림 문제 해결)
2. 사진이 적은 패턴 보강: 역헤드앤숄더, 상승·하락추세, 횡보, 삼중천장, 헤드앤숄더
3. SigLIP 2 + 분류기 실험 추가 (모델 파일 내려받을 환경 마련 후)
4. N자형은 마지막 상승이 충분히 보이게 자르기 (자르기 규칙 수정)
