# 4단계 준비. 데이터 수집과 재학습 규칙

## 폴더 구조

```text
data/
  원본캡처/   HTS 화면 전체 캡처 (원본 보관)
  학습용/<패턴>/   AI가 배우는 사진
  시험용/<패턴>/   실력 확인용 사진 (학습에 쓰지 않음)
```

패턴 폴더 11개: 쌍바닥, 삼중바닥, 역헤드앤숄더, N자형, 상승추세 / 쌍봉, 삼중천장, 헤드앤숄더, 역N자형, 하락추세 / 횡보

## 1차 자동 수집 (2026-11-17)

- 300분봉 화면 10장(원본01~10)에서 규칙 코드로 패턴 후보 48장을 잘라 학습용에 추가
- 자른 사진 규격: 가로:세로 3:2, 450×300, 빨강·파랑 봉만 남김(십자선·글자·팝업 제거)
- 사용자 지시로 후보 전체를 학습용에 넣음. 의심 사진(쌍봉_04·10·13, N자형_09, 헤드앤숄더_01·03, 쌍바닥_06)은 첫 학습 결과의 실패 분석 때 다시 확인
- 확인용 모음 그림: `자동후보_모음_1차.png`

## 앞으로의 흐름 (매매하며 계속 쌓기)

1. 매매 중 해당 패턴이 보이면 캡처 (십자선 없이, 위아래 안 잘리게)
2. **새 캡처는 먼저 `시험용/<패턴>`에 넣는다** → 학습에 쓴 적 없는 새 날짜라서 공정한 시험이 됨
3. 시험용이 패턴마다 3~5장 쌓이면: 현재 모델로 시험 → 결과 기록
4. 시험이 끝난 사진은 `학습용`으로 옮기고 **재학습**
5. 3~4를 반복하며 정확도 변화를 기록 (과제의 "개선 효과 검증" 자료)

## 하락 쪽 사진 늘리기

중심선 그림을 위아래로 뒤집고 빨강·파랑을 맞바꾸면 반대 패턴이 된다 (학습 때 코드로 자동 처리).
쌍바닥↔쌍봉, 삼중바닥↔삼중천장, 역헤드앤숄더↔헤드앤숄더, N자형↔역N자형, 상승추세↔하락추세, 횡보↔횡보
