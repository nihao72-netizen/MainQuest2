# 5단계 PoC 구현 지시문 (Claude Code에게 줄 것)

> 강의 "만들기" 절의 지시문 항목(모델·실행 위치·외부 전송 금지 / 값은 인자로 / 점수는 반올림 없이 / 중간 산출물 보존 / 눈으로 확인할 결과)을 따라 작성.
> 10번 결과 정리가 끝난 뒤 아래 "지시문" 부분을 그대로 붙여 넣는다.

## 지시문

```text
CLAUDE.md, problem_definition.md, model_comparison.md, 진행기록 09·10을 읽고 PoC 1차 버전을 만들어 줘.
목표: HTS 화면을 정기적으로 캡처해서 큰 봉 차트의 방향(상승/하락/없음)을 판정하고 기록하는 프로그램.
주문·매매와는 연결하지 않는다. 알림과 기록만 한다.

[구성]
1. 학습: 학습용 68장 전체로 YOLO11n-cls 3분류·11분류 모델을 각각 최종 학습해 models/ 에 저장.
   (교차검증과 같은 설정, 뒤집기 증강 포함. 학습 날짜와 사진 수를 모델 옆 json에 기록)
2. 캡처: 화면 전체를 캡처 (mss 등 PC 안에서 동작하는 라이브러리). 간격은 인자로 (기본 5분, 1회만 실행하는 옵션도).
3. 영역 자르기: 위쪽 큰 봉 차트의 그래프 영역만 자른다.
   - 좌표는 config 파일로 받고, 처음 한 번 좌표를 정하는 도우미 스크립트를 따로 만든다
     (캡처 한 장을 저장하고, 원본캡처에서 쓴 방법처럼 초록 축 막대로 영역을 자동 추정해 보여 주기).
   - 빨강·파랑 봉만 남기는 전처리는 학습 때와 똑같이 한다 (같은 함수를 import).
4. 판정 창: 학습 사진은 패턴 하나를 담은 잘린 사진이었으므로, 실제 화면에서는
   "오른쪽 끝(지금)에서 끝나는 최근 구간"을 여러 폭(예: 최근 100·150·200봉에 해당하는 너비)으로 잘라 각각 판정한다.
   폭 목록은 인자로 받는다. 각 폭의 판정을 모두 기록한다.
5. 알림 규칙: 3분류와 11분류(방향으로 변환)가 같은 방향이고 "없음"이 아닐 때만 "알림",
   의견이 갈리면 "애매(쉬어 가기)", 둘 다 없음이면 "없음". 이 규칙도 함수 하나로 분리해 바꾸기 쉽게.
6. 출력:
   - 콘솔에 한 줄 요약: 시각, 판정, 3분류 결과와 점수, 11분류 결과(참고: 쌍바닥과 비슷 등)와 점수
   - 기록 CSV(logs/): 시각, 창 폭, 두 모델의 결과와 모든 클래스 점수(반올림하지 말 것), 최종 판정
   - 판정에 쓴 잘린 사진에 결과 글자를 얹은 확인용 이미지를 logs/images/ 에 저장
   - (선택) 윈도우 알림 팝업은 "알림"일 때만

[지켜야 할 것]
- 모든 처리는 내 PC에서. 캡처를 외부로 보내지 말 것. 외부 AI API 쓰지 말 것.
- 판정에 쓰는 값(간격, 창 폭, 영역 좌표, 알림 규칙)은 코드에 박지 말고 인자나 config로.
- 점수는 반올림하지 말고 그대로 저장. "확률"이 아니라 "점수"라고 표시.
- 중간 산출물(캡처 원본, 잘린 사진)은 날짜·시각 이름으로 저장하고 덮어쓰지 말 것. 보관 개수는 인자로.
- 학습 때와 실제 판정 때 전처리가 같은지 확인하는 테스트를 하나 넣어 줘
  (같은 원본캡처 사진을 두 경로로 처리해서 결과가 같은지).
- 시험용 폴더 사진으로 이 PoC의 판정 함수를 돌려 점수를 내는 평가 스크립트도 만들어 줘.
  (시험 후 라벨이 의심되는 사진은 고치지 말고 "라벨 의심"으로 따로 기록, 점수는 원래 정답으로)
- 실행 방법을 README 초안(실행방법 위주)으로 정리.
- 초보자라서 각 단계 끝날 때마다 무엇을 했는지 쉽게 설명해 줘.
```

## 미리 생각해 둘 점

| 문제 | 왜 중요한가 | 지시문에서 다룬 곳 |
| --- | --- | --- |
| 학습 사진과 실제 화면의 차이 | 학습 사진은 "패턴 하나를 잘라 낸 사진", 실제는 "오른쪽 끝이 지금인 화면" → 같은 모델이 다르게 반응할 수 있음 | 4번 판정 창 (여러 폭으로 잘라 비교) |
| 전처리 불일치 | 학습 때와 다르게 자르면 성능이 조용히 떨어짐 | 전처리 공통 함수 + 테스트 |
| 점수를 확률로 오해 | 강의 6장 | 점수 표시 규칙 |
| 라이선스 | YOLO(Ultralytics)는 AGPL-3.0. 개인 사용·과제는 문제없음 | model_comparison.md 2장 |
